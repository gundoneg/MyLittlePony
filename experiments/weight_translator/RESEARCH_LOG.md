# Журнал итеративного улучшения переводчика весов

Цикл: **гипотеза → математическое обоснование → тест → анализ**. Цель — поднять качество
переноса (zero-shot и warm-start) на held-out задачах, не теряя точную gauge-инвариантность.
Метрика gauge-робастности уже упёрта в машинный ноль (feat_std≈2e-16) — её не улучшить;
работаем над переносом.

Зоопарк доноров кешируется (`lab.py`), варианты переводчика сравниваются на одном зоопарке.
Бейзлайн для всех: random-init B, дообученный k шагов.

---

## Итерация 0 — Бейзлайн (linear hypernet)
**Механизм:** `θ_B = θ0 + M·z`, `z = MLP(features(A))`; режим признаков `inv`.

**Результат (--full, 32+8):**
- inv: zero-shot 0.103, warm-start **0.564**, random 0.327; feat_std 2.1e-16.
- raw: warm 0.212; qr: warm 0.291 (оба < random — перенос по сырым/канон. весам вредит).

**Анализ:** инвариантность идеальна; warm-start уверенно > random; но **zero-shot ≈ случайность**
(1/V≈0.083). Узкое место — zero-shot: H не «записывает» нужную перестановку σ в B напрямую.

## Итерация 1 — Ёмкость H (нелинейная гиперсеть `mlp`)
**Гипотеза:** zero-shot ограничен ёмкостью линейного `θ0+M·z` (rank d_z=8).
**Тест (smoke 6+4):** linear warm=0.330 / mlp warm=0.329 — **идентично**, zero-shot ~0.09 у обоих.
**Анализ:** ёмкость — НЕ узкое место. Гипотеза отвергнута.

## Итерация 2 — Структурный перенос словаря (`structured`)
**Гипотеза:** σ несут словарные матрицы донора; предсказать `B.emb=A.emb·Wee`,
`B.unemb=Wuu·A.unemb` напрямую → zero-shot вырастет.
**Тест (smoke):** structured warm=0.275 ≈ random 0.276 — **не помогло, даже чуть хуже**.
**Анализ (ключевой!):** каждый донор обучен независимо ⇒ имеет **свой произвольный базис
остаточного потока** (глобальный O(d)-gauge, различающийся МЕЖДУ донорами). `A.emb` живёт в
приватном базисе донора i; единая общая карта `Wee` не может согласовать базисы всех доноров.
То есть мы скормили H **базис-зависимый** признак — ровно тот класс, что мы критиковали. Это
именно «глобальный gauge остаточного потока» из §2 мат-дока — самая консеквентная симметрия.

## Итерация 3 — Базис-инвариантные признаки задачи (G и S_pos)
**Гипотеза:** zero-shot блокирует глобальный базисный gauge между донорами. Нужны признаки,
инвариантные к одновременному сопряжению `M→PᵀMP`, и при этом несущие факторы задачи `f_τ=D_σ∘Shift_k`.
**Мат-обоснование:**
- **σ-фактор:** `G = emb·unemb` (V×V, токен×токен) — при глоб. ортогональном P:
  `emb→emb Pᵀ`, `unemb→P unemb` ⇒ `G→emb PᵀP unemb = G`. **Инвариант** и прямо кодирует σ.
- **k-фактор:** `S_pos = pos·M_QK·posᵀ` (L×L, позиционные логиты внимания):
  `pos→pos Pᵀ`, `M_QK→P M_QK Pᵀ` ⇒ `S_pos` инвариантен; argmax по строке ≈ лаг k.
- Дополнительно — **сингулярные спектры** операторов (инвариант к `M→PᵀMP` для ортогон. P).
Эти признаки заменяют базис-зависимые сырые emb/unemb/pos.
