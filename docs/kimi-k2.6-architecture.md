# Архитектура Kimi K2.6 (Moonshot AI)

> Отчёт по результатам глубокого исследования (4 параллельных веб-агента: релиз/параметры,
> MoE/attention, обучение/MuonClip, сравнение с DeepSeek). Дата составления: 30.05.2026.

## TL;DR
Kimi K2.6 — флагманская открытая (Modified MIT) агентная модель Moonshot AI, релиз ~20.04.2026.
Это разреженная **MoE-модель класса 1 трлн параметров** (≈**1.04T всего / 32B активных** на токен),
сохраняющая ядро архитектуры семейства K2 (стиль DeepSeek-V3) и добавляющая **нативную
мультимодальность** через визуальный энкодер **MoonViT (~400M)**. Контекст **256K**, нативный **INT4**.

## Оговорка о достоверности
- **Ядро архитектуры K2** (1T/32B, MoE+MLA, 384 эксперта, 61 слой, 64 головы, MuonClip,
  15.5T токенов) — **высокая достоверность**: подтверждено техотчётом arXiv:2507.20534 и
  карточками моделей на Hugging Face.
- **Специфика именно K2.6** (релиз ~20.04.2026, MoonViT, мультимодальность) — **средняя
  достоверность**: отдельного техотчёта K2.6 нет, прямой fetch официальной карточки HF и
  arXiv в ходе исследования возвращал HTTP 403, факты собраны из зеркал (NVIDIA, Microsoft
  Foundry, Cloudflare, DeepInfra, Verdent). Рекомендуется сверить с официальной карточкой
  `moonshotai/Kimi-K2.6`, когда она будет доступна.
- **Латентные размерности MLA** (`kv_lora_rank=512` и т.д.) — выведены из родства с DeepSeek-V3,
  требуют проверки по `config.json`.

## Ядро LLM-архитектуры (наследуется от K2, высокая достоверность)
| Параметр | Значение |
|---|---|
| Тип | Sparse Mixture-of-Experts (MoE), decoder-only Transformer |
| Всего параметров | ~1.04 трлн |
| Активных на токен | 32 млрд |
| Слоёв | 61 (1 dense FFN + 60 MoE; `first_k_dense_replace=1`) |
| Экспертов | 384 routed + 1 shared; на токен выбирается 8 routed (+shared) |
| Hidden dim | 7168 |
| Промежуточная размерность эксперта | 2048 |
| Внимание | **MLA (Multi-head Latent Attention)**, **64 головы** |
| Активация FFN | SwiGLU (SiLU-gated) |
| Словарь | 160K, BPE поверх tiktoken |
| Контекст | 256K (262 144) токенов |
| Квантизация | нативный INT4 (QAT на MoE-весах) |

Латентные размерности MLA, унаследованные от DeepSeek-V3 (требуют проверки по `config.json`):
`kv_lora_rank=512`, `q_lora_rank=1536`, `qk_nope_head_dim=128`, `qk_rope_head_dim=64`, `v_head_dim=128`.

## Что нового в K2.6 (средняя достоверность — нет техотчёта)
- **Нативная мультимодальность**: визуальный энкодер **MoonViT (~400M)** проецирует
  изображения/кадры видео в эмбеддинг-пространство. Введён в K2.5, сохранён в K2.6. (K2 и
  K2 Thinking были текстовыми.)
- **Стабильность на 256K** и длинных агентных горизонтах — основной заявленный прирост K2.6
  относительно K2.5, без изменения размера/ядра.
- Режимы **thinking / non-thinking**. Лицензия **Modified MIT**.

## Обучение (по техотчёту K2, высокая достоверность)
- **Оптимизатор MuonClip** = Muon + **QK-Clip**. QK-Clip борется с «взрывом attention-логитов»
  (макс. логиты превышали ~1000): после шага оптимизатора пере-масштабирует веса Q/K тех голов,
  где логит превышает порог **τ=100**. Результат — претрейн **без loss-спайков**.
- **Претрейн: 15.5 трлн токенов**. Пост-тренинг: синтез агентных данных (SFT) + совместный RL
  с проверяемыми наградами и self-critique по рубрикам.
- **K2 Thinking**: нативный **INT4 через QAT** на MoE (~2× ускорение генерации), устойчивые
  **200–300 последовательных вызовов инструментов**.

## Сравнение с DeepSeek-V3 / R1
| | DeepSeek-V3 | Kimi K2 / K2.6 |
|---|---|---|
| Всего / активных | 671B / 37B | ~1.04T / 32B |
| Routed экспертов | 256 | **384** |
| Активируется на токен | 8 (+1 shared) | 8 (+1 shared) |
| Головы внимания | 128 | **64** |
| Dense-слоёв перед MoE | 3 | **1** |
| Слоёв всего | 61 | 61 |
| Hidden dim | 7168 | 7168 |
| Токенов претрейна | 14.8T | 15.5T |

Идея K2: тот же каркас DeepSeek-V3, но **выше разреженность** (384 эксперта вместо 256 → больше
ёмкости при меньших активных параметрах) и **дешевле инференс длинного контекста**
(64 головы вместо 128, 1 dense-слой вместо 3). **DeepSeek-R1** = та же архитектура, что V3,
отличие лишь в RL-пост-тренинге (распространённое в сети утверждение «у R1 больше экспертов» —
не подтверждено, вероятно ошибочно).

## Эволюция семейства
K2 (07.2025, 128K) → K2-0905 (256K) → K2 Thinking (11.2025, reasoning + INT4) →
K2.5 (мультимодальность, MoonViT) → **K2.6 (~04.2026, стабильность на 256K)**.
