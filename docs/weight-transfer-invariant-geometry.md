# Изящная математика переноса весов: инварианты, геометрия фактора, Фишер–Рао

> Строгий разбор: есть ли более элегантное решение проблемы симметрий весового пространства, дающее
> **максимальное качество и стабильность**, чем инженерная «комбинация трёх приёмов» из
> `weight-symmetry-circumvention.md`. Дата: 30.05.2026.
>
> **Главный вывод:** не чинить симметрии патчами (канонизация), а устранить их в корне, работая с
> внутренними gauge-инвариантными объектами. Это один принцип на трёх уровнях — алгебра / геометрия
> / вероятность, — и они эквивалентны. Ключевое наблюдение: **gauge-орбита = слой расслоения
> `W→W/G` = ядро метрики Фишера = класс с равными полными инвариантами.**

## 0. Тезис
Симметрии весового пространства делают наивную регрессию `‖Ĥ−θ‖²` некорректной. Инженерный ответ
(канонизация + эквивариантность + поведенческий лосс) работает, но канонизация **разрывна** и
хрупка. Изящный ответ: работать с **внутренними инвариантными объектами**, где симметрии исчезают
по построению.

## 1. Единый объект: gauge-орбита
Пусть `G` — группа функцию-сохраняющих преобразований весов (для MLP `G=∏ᵢ S_{dᵢ}`, действие
`Wᵢ↦PᵢWᵢPᵢ₋₁ᵀ`; для внимания — см. §3). Орбита `[w]=G·w` одновременно есть:
- **(a)** слой главного расслоения `π: W→W/G` (геометрия, §4);
- **(b)** нуль-пространство метрики Фишера `F(θ)` в точке (вероятность, §5);
- **(c)** класс эквивалентности с одинаковыми значениями полных инвариантов (алгебра, §3).

Эти три описания совпадают. Работать «правильно» = работать на `W/G`.

## 2. Инвентарь симметрий и максимальная группа трансформера
Помимо перестановок `Sₙ` и ReLU-масштаба `(ℝ₊)ⁿ` (монорная группа, Godfrey 2022, 2205.14258), у
трансформера на общем страте максимальная gauge-группа
`G_max = (GL(d_k)^h × GL(d_v)^h) ⋊ S_h`, алгебра `⊕ₕ 𝔤𝔩(d_k) ⊕ₕ 𝔤𝔩(d_v)`: QK и VO факторизуются по
головам независимо, головы переставляются `S_h` (RoPE сжимает QK-фактор до коммутанта поворотов).
Плюс **глобальный** gauge остаточного потока `O(d)/S_d` (сетевой, не послойный). Источник: Maximal
Gauge Symmetry in Transformer Architectures (OpenReview K1df8mmncF), 2412.14543.

## 3. Алгебраический уровень: теория инвариантов
**Теорема (FFT, Вейль).** Кольцо O(d)-инвариантных полиномов векторов `v₁,…,vₙ` порождается
попарными скалярными произведениями `⟨vᵢ,vⱼ⟩` — **Грам-матрицей** `G=VᵀV`. Для GL нужны
векторно-ковекторные пары `⟨φₐ,vᵢ⟩` (у GL нет нетривиальных инвариантов одних векторов).

**Следствие (внимание).** Логиты `qᵀk = xᵀ W_Qᵀ W_K x'` зависят от QK только через бислинейную форму
`M_QK = W_Qᵀ W_K`; путь значений — только через `M_OV = W_O W_V`. Это полные инварианты непрерывного
gauge (GL-аналог Грам-матрицы). **Подавать надо `M_QK`, `M_OV`, а не сами `W_Q,W_K`.**

**Полнота = без потерь.** Инвариант `Φ` *разделяющий*, если `Φ(x)=Φ(y) ⇔ x,y` в одной орбите —
тогда `Φ` есть достаточная статистика класса функций (любая инвариантная функция факторизуется через
`Φ`). Villar «scalars are universal» (2106.06610): всякая O(d)-инвариантная функция = `h({⟨vᵢ,vⱼ⟩})`,
эквивариантная = `Σᵢ gᵢ({⟨·,·⟩})·vᵢ`. Dym–Gortler (2205.02956): достаточно `2D+1` обобщённых
инвариантов, чтобы разделить все орбиты. Стабильная (bi-Lipschitz) полнота — Cahill et al. 2024,
sorting-embeddings 2410.05446: **разделяет ⇔ bi-Lipschitz** = «без потерь И стабильно».

**Стабильность: гладкость инвариантов vs разрывность канонизации (решающий пункт).**
- `V↦VᵀV` и `(W_Q,W_K)↦W_QᵀW_K` — полиномиальны, значит `C^∞` **всюду**, включая вырожденные спектры.
- Канонизация через SVD/собственные векторы **разрывна**: при сближении сингулярных значений выбор
  фрейма `U,V` неустойчив (Davis–Kahan: возмущение подпространства `≤ ‖E‖/gap → ∞`), а при кратных —
  неоднозначен. **Теорема невозможности (Dym–Lawrence–Siegel, 2402.16077):** для `O(d), SO(d), Sₙ`
  **не существует непрерывной эквивариантной канонизации/фрейма**.
- Подтверждение в ML: SPE (2310.02579) обрабатывает **проектор** `P=Σ vᵢvᵢᵀ` (инвариант базиса)
  вместо самих собственных векторов — и получает доказуемую устойчивость; SignNet/BasisNet
  (2202.13013) показывают неустойчивость жёсткого разбиения по собственным значениям.

⇒ **Инварианты строго лучше канонических фреймов** для стабильности.

**Перестановочный (дискретный) случай.** Полные инварианты мультимножества: сортированный вектор /
первые `n` степенных сумм `pₖ=Σ xᵢᵏ` / элементарные симметрические (связаны тождествами Ньютона).
Графовые: WL-тест (MP-GNN ровно силы 1-WL, Xu 2019; 1-WL неполон на регулярных графах — нужна `k`-WL
иерархия). **Цена полноты (Wagstaff, 1901.09006):** для непрерывной sum-декомпозиции Deep Sets
латентная размерность должна быть `≥ n` — иначе пулинг не разделяет.

**Полная инвариантная система координат блока** (на общем страте, гладкая в непрерывной части):
- QK/VO: `{M_QK^(h), M_OV^(h)}ₕ` — полиномиальны, `C^∞`;
- перестановка голов `S_h`: симметризовать набор форм степенными суммами/сортированными спектрами
  (`≥ h` координат);
- MLP `S_m` (+ReLU-масштаб): мультимножество-инварианты каналов после scale-нормировки;
- `S_d` остаточного потока действует сопряжением `M↦PMPᵀ` — спектральные/WL-инварианты (полны до WL).

Гладкость: непрерывный gauge — `C^∞`; дискретный — лишь Липшиц (sorting/WL), но это доказуемо лучше
разрывной канонизации (неустранимая цена разделения орбит).

## 4. Геометрический уровень: фактор-многообразие `W/G`
**Структура.** Если `G` (группа Ли) действует гладко, свободно и собственно, то `W/G` — гладкое
многообразие, `π:W→W/G` — главное `G`-расслоение (слайс-теорема Палэ 1961); хаусдорфовость — из
собственности. На общем страте (полноранговые веса) действие свободно; вырожденные веса дают особые
страты (орбифолд).

**Квотиентная метрика.** При `G`-инвариантной метрике (перестановки — изометрии)
`d_{W/G}([x],[y]) = min_{g∈G} ‖x − g·y‖`. `π` — риманова субмерсия: `T_xW=𝒱_x⊕ℋ_x`, геодезические
`W/G` — проекции горизонтальных геодезических (формула кривизны О'Нилла добавляет неотрицательные
члены). Регрессия орбиты в `W/G` корректна; `min_g` — это и есть шаг выравнивания (re-basin).

**Многообразия инвариантов внимания.** Под правым `GL/O(d_k)`:
- подпространство столбцов `W_Q` — точка **Грассманиана** `Gr(d,d_k)`; ортонормированный фрейм —
  **Штифель** `St(d,d_k)`; геодезическое расстояние = `ℓ₂`-норма главных углов (Edelman–Arias–Smith
  1998).
- форма `M_QK` (фикс-ранг/SPD) — на **конусе SPD** с метриками: **аффинно-инвариантной** (AIRM,
  `d=‖log(A^{-1/2}BA^{-1/2})‖_F`, CAT(0) ⇒ единственные барицентры), **Bures–Wasserstein** (`=W₂`
  между гауссианами, мягче к обусловленности) или **log-Euclidean** (плоская, дешёвая).

**Mode connectivity = выпуклость фактора.** Entezari 2022 (2110.06296): по модулю перестановок
SGD-решения линейно связаны (барьер `→0`), т.е. в `W/S_n` — один приближённо выпуклый бассейн. Git
Re-Basin (2209.04836): `π` ищется LAP-координатным спуском (weight matching) / Sinkhorn; REPAIR
(2211.08403) чинит провал дисперсии на середине.

**Перенос = геодезическая/барицентр в факторе.** OT-fusion (Singh–Jaggi, 1910.05653) = мягкая
(дважды стохастическая) релаксация перестановочного выравнивания + барицентр Вассерштейна по
нейронам. Барицентр в факторе: `arg min_{[w]} Σ ωᵢ d_{W/G}([w],[wᵢ])²` (Фреше/Карчер).

**Оптимизация, инвариантная по построению.** Риманов SGD (Bonnabel 2013, 1111.5280):
`x_{t+1}=Exp_{x_t}(−γ_t ∇̂f)` на `St/Gr/SPD` — у градиента нет вертикальной (gauge) компоненты, шаг
не тратится на переразметку ⇒ максимальная устойчивость.

## 5. Вероятностный уровень: информационная геометрия
**Фишер–Рао живёт на функции.** Сеть задаёт `p_θ(y|x)`; `F(θ)=E[∇log p ∇log pᵀ]` — пуллбэк метрики
Фишера–Рао. **Теорема (Ченцов):** Фишер — единственная (с точностью до масштаба) метрика,
инвариантная относительно достаточных статистик (Ay–Jost–Lê–Schwachhöfer, 1306.1465). Симметрия
весов оставляет `p_θ` неизменной ⇒ это **изометрия** Фишера–Рао; всё, заданное на функции (KL,
расстояние Фишера–Рао), gauge-инвариантно.

**Поведенческий лосс нативно Фишер–Рао.** `KL(p_{θ₀}‖p_θ)=½ Δθᵀ F(θ₀) Δθ + O(‖Δθ‖³)` — Фишер есть
локальная метрика выходного KL; дистилляция Хинтона минимизирует KL на смягчённых логитах ⇒ неявно
работает в геометрии Фишера–Рао. ⇒ **поведенческий/функциональный лосс gauge-инвариантен по
построению** (зависит лишь от функции).

**Натуральный градиент инвариантен к репараметризации.** `g̃=F⁻¹∇L` (Amari 1998): при `θ=φ(ξ)`,
`F↦JᵀFJ`, `∇L↦Jᵀ∇L`, так что `F⁻¹∇L` — контравариантный вектор (одно и то же геометрическое
направление). **Фишер сингулярен ровно вдоль gauge-орбит** (Fukumizu 1996: `F`≻0 ⇔ сеть неприводима;
сингулярная теория обучения Ватанабе). В сингулярном случае берут Moore–Penrose `F†` —
минимально-нормовый шаг, инвариантный в смысле pushforward (van Oostrum–Müller–Ay, 2206.15273).

**Честно про цену.** Полный Фишер `O(P²)` память / `O(P³)` обращение — неподъёмно; K-FAC (1503.05671)
даёт блочно-кронекерово приближение, но блочность нарушает кросс-блочную инвариантность ⇒ **лишь
приближённо** gauge-инвариантно; использовать *истинный* (model-sampled), не эмпирический Фишер
(Kunstner 1905.12558). Вывод: поведенческий лосс уже даёт инвариантность *цели*; натуральный градиент
добавляет инвариантность *динамики* — теоретический «север», на практике спектр (functional → +Adam
→ +K-FAC → full NGD).

## 6. Синтез: три уровня — один принцип. Изящный рецепт
Алгебра/геометрия/вероятность — это одно утверждение (см. §1). Максимально изящный, без потерь и
стабильный переводчик весов `H`:
1. **Кодировать сеть в полные гладкие инварианты** (§3): `M_QK^(h), M_OV^(h)` (снимают весь
   непрерывный GL-gauge, гладко всюду) + мультимножество-инварианты по головам/каналам +
   scale-нормировка. Это убирает хрупкую разрывную канонизацию из «комбинации».
2. **Метасеть на инвариантах** (новизна — в литературе не собрано): Villar-коэффициенты
   (O(d)-инвариантность по построению) + GMN-message passing по графу параметров (перестановочная
   эквивариантность, приём разных архитектур, 2312.04501) + **frame averaging** (Puny 2110.03336,
   непрерывно) для остаточных компактных симметрий. Никакого `argmax`-канона.
3. **Перенос как геодезическая/барицентр в факторе** (§4): головы↔головы — OT под
   Грассманиан+Bures-стоимостью; внутри головы — геодезическая проекция `Gr/St` (главные углы) и
   `BW/AIRM` геодезическая форм; несколько доноров — барицентр Фреше.
4. **Обучать поведенческим лоссом** (§5, нативно Фишер–Рао; gauge-инвариантность цели бесплатно);
   опц. **натуральный градиент** (`F†`) для инвариантности динамики, реалистично — K-FAC/диагональ.
5. **Lift обратно** в конкретные `W_Q,W_K,…` любой факторизацией `M_QK` (выбор представителя —
   свободный gauge); цель читает лишь инвариантную функцию ⇒ выход определён по модулю gauge.

**Почему строго лучше прежней «комбинации трёх приёмов».** Разрывную канонизацию (самое хрупкое
звено) **заменяем гладкими полными инвариантами**; лосс, архитектура и оптимизатор перестают быть
тремя независимыми патчами и становятся гранями одного принципа «работать на `W/G`». Качество не
теряется (полный инвариант = достаточная статистика), стабильность максимальна (гладкость +
bi-Lipschitz + риманова/Фишер-инвариантность).

## 7. Что даёт максимум качества и стабильности
- **Качество (без потерь):** полные/разделяющие инварианты = достаточная статистика ⇒ потолок
  переводчика сохраняется (Villar; Dym–Gortler `2D+1`).
- **Стабильность:** (i) гладкость инвариантов vs доказанная разрывность канонизации
  (Dym–Lawrence–Siegel); (ii) bi-Lipschitz-разделение; (iii) Фишер–Рао инвариантна к репараметризации
  (Ченцов) + риманов SGD без вертикальной компоненты.

## 8. Открытые проблемы / честные оговорки
- Полнота инвариантов-произведений доказана для `O(d)/SO(d)`, **не для полного GL** — `M_QK`
  корректный GL-инвариант, но теорема полноты GL-инвариантных метасетей не установлена.
- Дискретная часть: цена Wagstaff `≥ n`; неполнота 1-WL; вырожденные страты (ранг-дефицит, кратные
  спектры) — где и инварианты теряют инъективность, и фреймы разрывны.
- Натуральный градиент `O(P³)` неподъёмен; приближения ослабляют саму инвариантность.
- Кросс-размерный перенос `Gr/BW` и вложение Фишера в мета-оптимизацию — эмпирически не показаны.
- **Ни одна опубликованная метасеть не инвариантна к полному непрерывному QK-gauge** — пункт §6.2 был
  бы новым результатом.
- Взаимодействие с LayerNorm (вычитание среднего), RoPE, остаточным потоком сжимает/ломает
  номинальную группу (`GL→O(d)`/фикс. масштаб) — выводить под конкретную архитектуру.
- Достоверность: теоремы (FFT, Ченцов, Davis–Kahan, Dym–Lawrence–Siegel, Villar, слайс-теорема) —
  высокая; точные `G_max`/RoPE-коммутант и формулировки из gauge-статей — из абстрактов (PDF давали
  HTTP 403), помечены.
