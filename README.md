# MyLittlePony

Обучаем новые модели без инференса на основе старых: **переводчик весов C** читает веса
модели A и выдаёт веса модели B (другая архитектура / глубина), без дообучения на данных
задачи в момент применения.

## Состояние проекта (фаза 10, итог)

Линия фаз 6–9 закончилась двумя негативными вердиктами; фаза 10 (переанализ + корректирующие
эксперименты) **пересмотрела оба** — они оказались артефактами конвейера/обучения, а не
свойствами задачи:

| Вердикт | Что оказалось | Эксперимент |
|---|---|---|
| «Перенос мелкие→глубокие невозможен (chance при любом alpha)» | 2 бага: gauge-порча per-block фич для l≥1 (`align.py` вращал qkv только блока 0) + рассогласование референс-рам между глубинами; после фиксов перенос ≈native, где глубина нерекурсивна | E0, `arch_translator/run_cover_fixed.py`, `README_phase10.md` |
| Остаточный разрыв при рекурсивной глубине (alpha=1) | Закрывается few-shot: 1–4 глубоких донора (17→53%, native 100%); знание глубины локализовано в **одном** параметре `M_block` (только его дообучить → 66%) | E3, `arch_translator/run_fewshot.py` |
| «Глубокое нутро реальной LLM несжимаемо» (фаза 9) | Артефакт голода по данным + end-to-end обучения сквозь компаундирование. Teacher-forced + cascade rank-16 LoRA на ОДНОМ экземпляре воспроизводит все 8 слоёв нутра Supra-50M до KL 0.55 (verbatim 7.27) | E1, `depth_entangle/e1_kaggle.ipynb` (Kaggle GPU), `README_entangle.md` |

**Рабочий рецепт, который из этого следует:** покрыть репертуар типов слоёв мелкими донорами
(уникальны только ранние слои + финальный), затем — горстка глубоких доноров на точечный
апдейт `M_block`; нутро реальной модели сжимается в «экземпляр + лёгкий пер-слотовый
адаптер», если фитить teacher-forced каскадом (компаундирование — главный враг, и оно
корректируемо).

## Финальная демонстрация тезиса (supra50m → Mercury-2 диффузия, переводчиком C)
`c_mercury_port.ipynb` (7 итераций, лог в `diffusion_port/README_c_port.md`): модель B создаётся
**исключительно** переводчиком C — `B* = C(supra50m)` = веса донора + пер-блочные поправки,
эмитируемые C в собственной SVD-раме каждой матрицы (вход gauge-инвариантен, выход ковариантен),
+ [MASK]-эмбеддинг. C учится сквозь diffusion-loss на **усечённых под-стеках самой supra**
(self-zoo), все данные — самогенерация донора, KD-цели — его же распределения. **B не обучается.**

Финальные числа (Kaggle 2×T4, ~32 мин): masked-CE B* **3.61/4.01/4.46/5.20** против пола
6.50–10.05 (донор AR 1.67); **реконструкция 23.5% vs 1.5%** с семантическим восстановлением
текста; контроль перемешанных сигнатур **10.68 vs 3.98** — C доказуемо читает пер-блочные веса;
**warm: перевод = фора ~100 шагов** полного дообучения. Генерация: после фиксов сэмплера
(дебиас филлеров, no-repeat-ngram) — тематический прото-текст **в классе качества самого
донора** (50M-донор сам генерит вырожденно: «- - - -»); беглость ограничена донором, не методом.
Путь к результату — 7 прогонов, каждый чинил одну диагностированную причину: ковариантность
выхода → совпадение распределений (self-zoo) → разнообразие корпуса → покрытие блоков → ёмкость
→ KD → сэмплер. Дорожe всего обошлись уроки №1 (рама) и №2 (распределение зоопарка).

## Ключевые уроки всей арки
1. **Общая система координат — это всё.** Без общей рамы (tied-init или data-align по
   активациям) zero-shot мёртв; с ней работает и масштабируется. Статические веса не несут
   базис — его извлекают активации на малой Q-A пробе (фаза 5: data-align 77–95%, глубина
   помогает).
2. **Per-block weight-tied гипернет** — правильная форма C для глубины: параметры не растут с
   L, специализация по слоям, native-depth перенос ~98%.
3. **Инварианты хрупки на практике:** оба «фундаментальных» провала были багами конвейера
   (полу-применённый gauge, чужая рама) или режимом обучения (без teacher forcing /
   каскада). Сначала чинить пайплайн, потом делать выводы о невозможности.
